## Dataset
- **Source:** Python Software Foundation (PSF) blog, from its public RSS feed:
  https://pyfound.blogspot.com/feeds/posts/default?alt=rss
- **What it contains:** the 20 most recent blog posts (title + post text). Each post is saved as a `.txt` file in `data/`.
- **License:** the posts belong to the Python Software Foundation and are publicly available on their blog. We use them only for this class exercise.

## Files
- `IR_InvertedMatrix_Workshop.ipynb` – the notebook (document collection, tokenizer, normalization, inverted index, phrase queries, positional index, TF-IDF).
- `README.md` – this file.

## How to run
```bash
pip install nltk feedparser requests pandas
```
Then open the notebook and run all cells (Kernel → Restart & Run All).
